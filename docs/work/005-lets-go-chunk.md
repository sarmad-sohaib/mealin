# 005 Let's go chunk

"Let's go" no longer means one task. It takes every Ready task that does not share Owns, one subagent each, and at most one Lane C task. One Ready task, a spike, or the catalog export stays a single task. A chain stops early. The next "let's go" reviews the open pull requests together.

Other way that was set aside: letting one "let's go" keep going into every task it unblocks. That would pass the review gate.
