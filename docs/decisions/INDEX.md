- 2026-11-28 [The fitness test scans Kotlin source](2026-11-28-architecture-fitness-scan.md): The architecture fitness test is an Android host test that reads Kotlin in the working tree. A `commonMain` import fails that test when the package starts with `android.`, `androidx.`, or `platform.`. An `expect` or `actual` declaration fails that test when the file's path from the repo root is not a line in `sharedLogic/expect-actual-allowlist.txt`. Comments, string literals, and directories named `build`, `.gradle`, and `.git` are not declarations.

- 2026-11-28 [iOS collects a store with SKIE](2026-11-28-skie-collects-the-store.md): iOS UI collects a `:sharedLogic` store with SKIE 0.10.16 on the `SharedLogic` framework from `:sharedLogic:linkDebugFrameworkIosSimulatorArm64`. Swift reads `store.state.value`, collects with `for await state in store.state`, sends a suspend intent with `try await store.apply(intent:)`, and switches a sealed value with `onEnum(of:)`. The spike package is not in the tree. The first iOS task that collects a store adds plugin `co.touchlab.skie` 0.10.16 to `:sharedLogic`. It keeps `embedAndSignAppleFrameworkForXcode`.

- 2026-11-27 [One task goes through a pull request, then a binary is uploaded only when an app changed](2026-11-27-team-loop.md): "Let's go" runs the lowest Ready task through a branch, a failing test commit, the implementation, and a pull request. The author asks the user for a missing fact or credential, including a Firebase JSON, and waits. The author does not invent it. The user starts a new chat and says "let's go" to review and merge after checks are green. After that merge, an `androidApp` or `iosApp` change is uploaded to Firebase App Distribution and TestFlight when `docs/distribution/REQUIRED.md` has values. The session does not start the next task. The app does not gain the Firebase SDK.
